**Demuestra:** modelado de datos, frontend interactivo, manejo de fuentes.
`Python` `Flask` `SQLAlchemy` `SQLite` `JavaScript` `Leaflet`

### 📊 [MarketLens AI](https://github.com/alvaroberrio23242-eng/marketlens-ai)
Plataforma de análisis de mercados: riesgo de portafolio, backtesting e IA explicable, separando estrictamente datos sintéticos de reales.
**Demuestra:** análisis de datos, APIs externas, rigor en trazabilidad.
`Python` `Flask` `pandas` `NumPy` `Plotly` `yfinance`

### ⭐ [ReviewTap](https://github.com/alvaroberrio23242-eng/reviewtap)
Plataforma web con autenticación y sesiones, lista para producción (SQLite en desarrollo, PostgreSQL en producción).
**Demuestra:** backend, seguridad básica, despliegue en Render.
`Python` `Flask` `SQLAlchemy` `PostgreSQL`

### 🎸 [RockQuest](https://github.com/alvaroberrio23242-eng/rockquest)
Plataforma interactiva sobre la historia del rock: bandas, artistas, décadas, subgéneros, récords y Grammys.
**Demuestra:** diseño de base de datos relacional y reutilización de arquitectura entre proyectos.
`Python` `Flask` `SQLAlchemy` `SQLite`

`Python` `Pygame` `WebAssembly`
